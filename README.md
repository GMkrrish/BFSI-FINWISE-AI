# BFSI-FINWISE-AI - Personal Finance Advisor Bot

An AI-powered personal financial advisory and portfolio management web application for the BFSI domain.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment:
   Copy `.env.example` to `.env` and add your API keys (optional):
   ```bash
   cp .env.example .env
   ```

3. Run development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

## Features
- **AI Financial Advisor**: Live AI assistance with fallback offline financial domain knowledge base.
- **Transaction & Expense Tracker**: Categorization, analytics, and spending charts.
- **Financial Goals Planner**: Track savings goals and milestone progression.
- **Authentication**: User accounts with isolated local storage data in `server/db.json`.
